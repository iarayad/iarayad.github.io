# Contents

This folder contains all the content files for the Quarto website:

- **`.qmd` files**: All Quarto markdown files for pages and posts
- **`images/`**: All image assets used in the website
- **`data/`**: Canonical YAML data used by the website and exported to application materials

## Structure

```text
contents/
├── _home.qmd          # Homepage content, included by index.qmd
├── research.qmd       # Research page
├── images/            # Image assets
│   ├── logo.svg
│   └── profile.jpg
└── data/              # Canonical data files
```
